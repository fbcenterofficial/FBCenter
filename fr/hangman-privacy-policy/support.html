1Problèmes fréquents

Je n'ai pas reçu le code de vérification ou l'e-mail de réinitialisation

Vérifiez d'abord vos spams. Si vous en avez demandé plusieurs, regardez le plus récent — seul le dernier code ou lien est valable, et en demander un nouveau annule le précédent.

Le code reçu ne correspond pas à ce que demande l'application

Saisissez exactement les chiffres de l'e-mail, sans espaces. Si le code est toujours refusé, demandez-en un nouveau — les codes expirent rapidement.

Le lien de réinitialisation n'ouvre pas l'application

Ouvrez le lien sur le téléphone où Hangmania est installée, puis touchez « Ouvrir Hangmania » sur la page qui s'affiche. Si la page indique que le lien a expiré, demandez-en un nouveau depuis l'application.

J'ai acheté Premium mais il n'apparaît pas

Vérifiez que vous êtes connecté au compte utilisé pour l'achat, puis touchez « Restaurer les achats » sur la page Premium. Si rien ne change, envoyez-nous votre reçu et l'e-mail du compte.

Je ne reçois pas de notifications

Vérifiez que les notifications sont autorisées pour Hangmania dans Réglages → Notifications du téléphone et que le mode Concentration / Ne pas déranger est désactivé. Après une réinstallation, le téléphone redemande l'autorisation. Les notifications n'arrivent que si vous êtes connecté.

Comment modifier mes choix publicitaires ?

Dans l'UE, au Royaume-Uni et en Suisse, ouvrez Réglages → Confidentialité des pubs dans l'application. Sur iPhone, vous pouvez aussi modifier le suivi dans Réglages → Confidentialité et sécurité → Suivi. Premium supprime complètement les publicités.

Je veux supprimer mon compte et mes données

Allez dans Réglages (ou Profil) → Supprimer le compte dans l'application. Cela supprime immédiatement le compte et toutes les données de jeu. Si vous n'avez plus accès à l'application, écrivez à fbcenterofficial@gmail.com depuis l'adresse du compte et nous le supprimerons manuellement sous quelques jours. Supprimer le compte n'annule pas l'abonnement — annulez-le via Apple ou Google.
